# Penalty Scout

A computer vision tool that analyzes penalty kicks from broadcast video
to reveal kicker and goalkeeper tendencies.

## The question

Can a Player's body posture before contact predict the shot direction?
And how early do goalkeepers commit to a side?

## Status

Work in progress

## Roadmap

- [ ] Extract body pose from penalty clips
- [ ] Identify striker and goalkeeper automatically
- [ ] Build a labeled penalty dataset
- [ ] Analyze striker tendencies and goalkeeper reaction time
- [ ] Generate a scouting report per a player
